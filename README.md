# 你好 👋 我是吴建豪 (Wu Jianhao)

> 2003 年生于广东河源，从小在湖北恩施偏远地区成长与受教育，接触互联网、电脑的时间较晚。

我常在互联网上以 **seegood** 自称。热衷于探索未知事物与学习新技能 —— 虽然常被自己笑称"爱博而情不专"。从高中接触摄影、大学狂热街头拍摄与剪辑，到毕业后沉迷于用 AI 构建网页、浏览器扩展与安卓应用，这一路都在折腾好玩的东西。

除了写代码，我还会做咖啡（业余）：从挑豆、研磨到萃取；也极其热爱散步和骑行（骑什么无所谓，能跑就行）。

### 我正在做的事

- **网页 / Web**：用 AI 构建各类网站与工具
- **浏览器扩展 / Browser Extensions**：解决实际小痛点的扩展程序
- **安卓应用 / Android Apps**：移动端的小作品
- 部分项目已获得不少使用者与资金赞赏
